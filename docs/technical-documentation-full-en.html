5. Database Technical Details

5.1 Entity relationship diagram (logical)

users (id) -----------------------------< documents (user_id)
  |
  +-- belongsTo hospitals (hospital_id)
  |
  +--< patient_companions >-- users
      (patient_id, companion_id, can_view_documents, relationship)
  |
  +--< companion_access_codes (patient_id)
  |
  +--< chat_messages (patient_id)
         |
         +-- sender_id -> users.id

conversation_last_seen (user_id, patient_id, last_seen_at)
ingest_logs (operational ingestion status history)

8. Non-Functional Notes

  • Localization is centralized in FE i18n maps with backend message key mapping.
  • Role authorization is enforced server-side by middleware and controller checks.
  • Unread chat totals are computed from conversation-level unread counts.
